Key ideas

  • A formula starts with =. Cell reference = column letter + row number (B2). Range = A1:A6 (from A1 to A6). Formulas update automatically when the data changes.
  • Relative reference (B2) changes when copied; absolute reference ($B$2) stays fixed.

VLOOKUP

[[fig:i_vlookup|VLOOKUP: the lookup value must be in the first column of the table range.]]
  • Tashi Dendup’s score: the names are in column B and the marks in C, so the table is B2:C5 and the marks are in column 2 of that table → =VLOOKUP("Tashi Dendup", B2:C5, 2, FALSE) = 78 → A [[P25 Q1a(x)]]. The lookup value must be in the first column of the table range, so the range must start at column B, not A.

Other features

  • Data Validation: restricts what can be typed, e.g. whole numbers between 1 and 100 for test scores → C [[P24 Q1a(i)]]. Conditional formatting colours cells by a rule; Filter shows rows that match a condition; Pivot table summarises data.
  • Total sales = units sold × unit price. In the table (C = Units Sold, D = Unit Price) the formula in E2 is =C2*D2 → B [[P24 Q1a(iii)]].

Choosing a chart

[[fig:i_chart_choice|Column, line, pie and scatter charts and when to use them.]]
  • Sales trend over five months → line chart (option D) because the line joins the points in time order and shows the rise and fall [[P25 Q1a(ix)]]. A pie chart shows parts of a whole; a column chart compares categories; a scatter plot shows the relationship between two numbers.
  • To make a chart: select the data → Insert → Chart → choose the type → add title and axis labels [[P24 Q4b]].

Solved questions

(i) Walking (the tallest bar, 12). (ii) The height of each bar shows the number of students using that mode of transport. (iii) Students not taking the bus = total − bus users = 40 − 10 = 30 students (4 + 8 + 6 + 12 = 30). (i) =MAX(E2:E5) (ICT marks are in column E). (ii) =AVERAGE(B2:E2) (Pema’s marks are in row 2, columns B to E). Mr Dorji should use the chart (Insert → Chart; a line chart) feature. It turns the figures into a picture, so trends and patterns such as rising or falling months and the best/worst month are seen at once, and comparisons are easier than reading numbers. =AVERAGE(A1:A6,">60") is not a valid conditional average: a text argument is not a criteria test (Excel gives #VALUE!), and the plain average of 45, 70, 55, 80, 40 is 58. None of the options is correct. The right formula is =AVERAGEIF(A1:A6,">60") = (70 + 80) ÷ 2 = 75. Ask your teacher; in the exam circle the option your key says.
