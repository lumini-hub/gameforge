Three forms of a quadratic

FormShows
Standard f(x) = ax² + bx + cy-intercept = c; a > 0 opens up, a < 0 opens down
Factored f(x) = a(x − p)(x − q)roots / x-intercepts p and q; axis of symmetry x = p + q|2
Vertex f(x) = a(x − h)² + vvertex (h, v); axis x = h
  • Roots: factorise or use x = −b ± b² − 4ac|2a. A quadratic with roots p and q is (x − p)(x − q) = 0.
  • Sketching: find roots, y-intercept (set x = 0), vertex (x halfway between roots), then draw a smooth parabola. Equivalent functions have the same expanded form.

Transformations of y = x² (mapping notation)

f(x) = a(x − h)² + vMapping (x, y) →
a: vertical stretch/compression; a < 0 reflection in the x-axis(x, ay)
h: horizontal shift (right if h > 0)(x + h, y)
v: vertical shift (up if v > 0)(x, y + v)
all together(x + h, ay + v)
