Some questions in the papers are faulty or unclear; they are marked (check): (a) 2025 Q1a(xv) — =AVERAGE(A1:A6,">60") is not a valid way to average values above 60 and none of the options is correct (the right function is AVERAGEIF, giving 75); (b) 2025 Q5e — the base case is printed as text == " " (a space); it should be the empty string "", otherwise the recursion would fail at the end; (c) 2024 Q5a — Pass and Continue are printed with capital letters; in Python they are pass and continue; (d) 2024 Q1c(v) and Q6c depend on how your textbook words the point; (e) 2024 Q4d — the scenario for the list-vs-set question was missing from my copy, so the answer is general. In the exam, answer the question as printed and add the correct term.

How marks are given (both papers)

  • Section A (40 marks): Q1(a) = 15 MCQs worth 2 marks each (30), Q1(b) 5 blanks (5), Q1(c) 5 true/false (5). Circle only ONE letter.
  • Section B (60 marks): attempt ALL of Q2–Q7, 10 marks each. Q2–Q4 are mostly short theory (cloud, citation, Excel, data structures); Q5–Q7 are programming; the last question (Q7) is always a long program.
  • Code answers: write correct indentation and colons; one mark per correct step (variable, loop, condition, print). Use meaningful names; comments are optional but help.
  • “Explain / justify / analyse”: give the point and the reason (“because…”). “Write the output”: write exactly what is printed, one value per line unless end=" ".
