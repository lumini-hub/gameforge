How to score full marks in Q7

  • Read the numbered steps (i)–(vii) and write one block of code for each, in order. Each step is worth the marks shown.
  • Use while True: for a menu that repeats until the user exits and break to leave it. Use if / elif / else for the choices and validate inputs (amount > 0, amount ≤ balance).
  • Convert input with int() or float(). Keep the indentation correct.

2025 Q7: Mobile banking simulation [10]

balance = 1000                                   # (i) [1]

while True:                                      # (ii) [2] menu repeats
    print("===== Menu =====")
    print("1. Check Balance")
    print("2. Deposit Money")
    print("3. Withdraw Money")
    print("4. Exit")
    choice = int(input("Enter your choice (1-4): "))

    if choice == 1:                              # (iii) [1]
        print("Current balance: Nu.", balance)

    elif choice == 2:                            # (iv) [2]
        amount = float(input("Enter amount to deposit: "))
        if amount > 0:
            balance += amount
            print("New balance: Nu.", balance)
        else:
            print("Error: amount must be greater than zero.")

    elif choice == 3:                            # (v) [2]
        amount = float(input("Enter amount to withdraw: "))
        if amount > 0 and amount <= balance:
            balance -= amount
            print("Updated balance: Nu.", balance)
        else:
            print("Error: invalid amount or insufficient balance.")

    elif choice == 4:                            # (vi) [1]
        print("Thank you for banking with us!")
        break

    else:                                        # (vii) [1]
        print("Invalid selection. Please choose a valid option.")
  • Marking points: balance variable (1); loop + menu + input (2); choice 1 (1); deposit with validation and update (2); withdraw with both conditions and update (2); exit message and break (1); invalid choice (1).

2024 Q7: School mess management [10]

def mess_system():
    print("School Mess Management Program")            # (i)

    items = ["rice", "pulses", "meat", "potato"]
    mess_qty = []                                       # (iii) list
    for item in items:                                  # (ii) ask 4 quantities
        qty = float(input("Enter quantity of " + item + " (kg): "))
        mess_qty.append(qty)

    if mess_qty[0] >= 1200:                             # (iv) rice check
        print("You have enough rice")
    else:
        mess_qty[0] = float(input("Enter new quantity of rice: "))
        print(mess_qty)                                 # updated list

    cost = [40, 50, 250, 30]                            # (v) cost per kg
    total = 0
    for i in range(4):
        total = total + mess_qty[i] * cost[i]
    print("Total expenditure: Nu.", total)

    if total <= 50000:                                  # (vi) budget
        print("You have enough budget")
    else:
        print("You don't have enough budget")

mess_system()                                           # call the function
  • Total expenditure = quantity × cost for each item, added together. Example: rice 1300, pulses 200, meat 100, potato 500 → 52 000 + 10 000 + 25 000 + 15 000 = Nu. 102 000 → “You don’t have enough budget”.

Common mistakes to avoid

  • Missing colon after if, while, def; wrong indentation; using = instead of == in a condition.
  • Forgetting int()/float() around input(); forgetting to update the balance; forgetting break for the Exit option; forgetting to call the function.
  • Case: True, False start with capitals; pass, continue, break are lowercase.
