  • An ordered, changeable collection that allows duplicates is a list [[P24 Q1b(i)]]. The structure that stores key-value pairs with unique keys is a dictionary [[P24 Q1b(iv)]]. Lists change; tuples stay fixed → C [[P25 Q1a(v)]].

Strings

  • A string is a sequence of characters; it is immutable: once created, its characters cannot be changed in place [[P25 Q4a]]. To “change” it you create a new string.
car = "Alto"
car[0] = "B"          # TypeError: strings are immutable
car = "B" + car[1:]   # new string "Balto" (the old one is replaced)
print(car)
  • P25 Q4b: modifying car shows immutability — direct item assignment fails, so a new string must be made (e.g. car = car + " 800" or "B" + car[1:]).

Lists: index, slice, methods

[[fig:i_list_index|Positive and negative indexes, and slicing.]] 
data = [10, 20, 30, 40, 50]
print(data[1:4])      # [20, 30, 40]  -> C
colors = ["red", "green", "blue"]
print(colors[-1])     # blue (last item)
my_list = ["Range", "function", "inbuilt", "variable"]
my_list.pop(2)        # removes index 2 ("inbuilt")
print(my_list)        # ['Range', 'function', 'variable']
  • Slice data[1:4] gives [20, 30, 40] (start included, stop not) → C [[P25 Q1a(viii)]]. colors[-1] counts from the end, so the output is blue [[P25 Q4c]]. After pop(2) the list is [‘Range’, ‘function’, ‘variable’] → D [[P24 Q1a(xi)]].
  • Methods: append(x), insert(i,x), remove(x), pop(i), sort(), len(list).

Tuples

my_tuple = (10, 20, 30, 40)
print(my_tuple[1])    # 20 -> B
  • Index starts at 0, so my_tuple[1] is 20 [[P24 Q1a(xiii)]]. Tuples use ( ) and cannot be changed; dictionaries use { } with key:value pairs and can be changed [[P25 Q4f]].

Sets

attended  = {"Rina", "Karma", "Sonam", "Tashi"}
submitted = {"Rina", "Sonam"}
not_submitted = attended - submitted      # or attended.difference(submitted)
print(not_submitted)                      # {'Karma', 'Tashi'}
  • Set operations: union |, intersection &, difference -. A set has no duplicates and no order [[P24 Q4d]].

Dictionaries

student = {"name": "Jampel", "age": 20}
student["grade"] = "A"          # add a new key
print(student)
vehicle = {'brand': 'Toyota', 'model': 'VigoHilux', 'year': 2021}
print(vehicle['model'])         # VigoHilux  (or vehicle.get('model'))
  • vehicle is a dictionary (keys and values) [[P24 Q5c(i)]]; read a value with its key: vehicle['model'] [[P24 Q5c(ii)]].
  • Student names with scores: a dictionary is better than a list: each name (key) is linked to a score (value) and the score is found instantly by name, while a list would need index positions or two parallel lists [[P25 Q4e]].
