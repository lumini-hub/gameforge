Variables & data types

  • A variable stores a value: age = 15. Python is case sensitive: Fruit and fruit are different variables → TRUE [[P25 Q1c(i)]]; "Apple" == "apple" is False [[P25 Q1a(xi): C]].
  • Valid variable names: letters, digits and underscore; cannot start with a digit; no spaces or hyphens; cannot be a keyword. school_1 is valid; school-1, school 1 and 1school are not → B [[P24 Q1a(xii)]].

Decisions (if / elif / else)

num_1 = 7
if num_1 > 0:
    print("positive")
elif num_1 == 0:
    print("zero")
else:
    print("negative")
  • Indentation (4 spaces) shows which lines belong to the block; each condition line ends with a colon.
  • Team A num_1 > 0 vs Team B num_1 >= 1 [[P25 Q6a]]: a positive number is any number greater than zero, including decimals like 0.5 and 0.01. >= 1 wrongly rejects these, so Team A is more appropriate (it works for all real numbers and says exactly what “positive” means).
