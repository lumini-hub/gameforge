Algorithm vs flowchart

  • An algorithm is a step-by-step set of instructions to solve a problem (written in words or pseudocode) [[P25 Q1a(xii): D]]. A flowchart is a diagram of the algorithm using standard symbols and arrows.

  • Process is a rectangle, not a parallelogram; the parallelogram is for input/output. “In a flowchart, process is represented by a parallelogram” is FALSE [[P25 Q1c(v)]].

Flowchart to code

  • Convert each symbol: input → input(); process → assignment or calculation; decision → if (or while when the arrow goes back); print → print(); start/stop → begin/end.

Solved questions

Algorithm vs flowchart (any two differences): (1) an algorithm is a written list of steps, a flowchart is a diagram; (2) an algorithm uses words or pseudocode, a flowchart uses symbols and arrows; (3) a flowchart shows decisions and loops visually, which is easier for beginners; an algorithm is faster to write. The flowchart sets row = 1; while row <= 5: set col = 1, while col <= row print “*” (same line) and add 1 to col; then print a newline and add 1 to row. Program (right-angled triangle of stars): 
row = 1
while row <= 5:
    col = 1
    while col <= row:
        print("*", end="")
        col += 1
    print()          # newline
    row += 1
Output:

**
***
****
*****
