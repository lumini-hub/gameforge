1.2 Question types and how to answer them

TypeLengthStrategy
MCQ1 mark eachRead the question twice; eliminate two options; choose the best answer (e.g. EXCEPT questions); circle only ONE letter.
Short answerabout 60 words (5 marks)Use PEEL: Point → Evidence from the text → Explain → Link. If it says "TWO reasons", give exactly two, each with its own evidence.
Long answerabout 150 words (10 marks)1 line introduction → 2–3 clear points, each with an example/quote → 1 line conclusion. Cover every part of the question (e.g. "THREE benefits", "FOUR features").
Creative / opinion60–150 wordsStay in character/format (advertisement, report, continuation). Link your ideas to the text.

Marks strategyEach 60-word answer = 5 marks → about 2 clear points with evidence. Each 150-word answer = 10 marks → about 3 points with evidence. Write in the present tense for literature (The lawyer renounces the money), use character names, and never retell the whole story.
