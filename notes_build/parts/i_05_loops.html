for loop and range()

[[fig:i_loops|How a while loop and a for loop run.]]
  • Use a for loop when you know how many times to repeat [[P24 Q1a(vii): D]]; use a while loop when you repeat as long as a condition is true [[P24 Q1c(iv): TRUE]].
  • range(stop) = 0 to stop−1; range(start, stop); range(start, stop, step). The stop value is never included.
[[fig:i_range|range() on a number line.]] 
for i in range(1, 4):      # 1 2 3
    print(i)
for j in range(3, 0, -1):  # 3 2 1
    print(j)
for i in range(2, 10, 3):  # 2 5 8
    print(i, end=" ")      # end=" " keeps output on one line
  • Output of for i in range(1,4) followed by for j in range(3,0,-1) [[P25 Q3e]]: 1 2 3 3 2 1 (each on its own line, six lines). range(2,10,3) with end=" " prints 2 5 8 [[P25 Q6c]].
  • Even numbers 1 to 15: for i in range(1,15): if i % 2 == 0: print(i) prints 2, 4, 6, 8, 10, 12, 14 → A [[P24 Q1a(iv)]] (option C misses 14; D prints 0).

break, continue, pass

KeywordEffect
breakstops the whole loop immediately
continueskips the rest of this iteration and moves to the next one [[P25 Q1b(iv): continue]]
passdoes nothing; a placeholder where a statement is needed
for i in range(8):
    if i == 1:
        pass          # does nothing
    elif i == 3:
        continue      # skip 3
    elif i == 5:
        break         # stop the loop
    else:
        print(i)      # prints 0, 2, 4

while loop

i = 0
while i < 5:
    if i == 3:
        break
    i += 1
    print(i)      # prints 1 2 3
  • Trace [[P25 Q1a(ii)]]: i = 0 → i becomes 1, print 1; → 2, print 2; → 3, print 3; now i == 3 so break before printing 4. Output 1, 2, 3 → C.
  • Remember to update the variable (i += 1); otherwise the loop never stops (infinite loop).

Python Turtle graphics

[[fig:i_turtle|The turtle draws a regular polygon: turn = 360 ÷ number of sides.]] 
import turtle
t = turtle.Turtle()

def draw_square():
    for _ in range(4):
        t.forward(100)
        t.right(90)

draw_square()       # calling the function runs the drawing
turtle.done()
  • Six sides with 60° turns draw a hexagon [[P24 Q1a(ix): D]].
