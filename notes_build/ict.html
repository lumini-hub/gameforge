1 · Cloud Computing & Google Workspace
P25 Q1a(iii,vi),b(i),c(iii),Q2b,c,d · P24 Q1a(ii,viii),c(i),Q2b,Q3a

Key ideas

  • Cloud computing = using servers, storage and software over the internet instead of on your own computer; you pay for what you use. Cloud services provide services over the internet → TRUE P25 Q1c(iii).
  • Cloud storage (e.g. Google Drive) keeps files on remote servers instead of a local device P25 Q1b(i): servers. You can open them from any device with internet.

Benefits of cloud storage

  • Lower upfront cost: no need to buy servers and hard disks; pay a small monthly fee (pay-as-you-go) P24 Q2b(i).
  • Scalability: add or remove storage when the business grows or in busy seasons, instantly P24 Q2b(ii).
  • Backup and recovery: copies are kept in several data centres, so data can be restored after hardware failure, fire or theft P24 Q2b(iii).
  • Access and sharing: work from anywhere, share links, edit together; automatic updates and reduced maintenance.
  • Risks: needs internet, security/privacy concerns, monthly cost, depends on the provider.

2 · Digital Citizenship: Copyright, Licences & Citation
P25 Q1a(i,iv,xiii),b(iii),c(iv),Q3a,b,c · P24 Q1a(v,x),b(ii,iii),c(v),Q3b,Q4a

Key ideas

  • Copyright = the exclusive legal right given to the creator to print, publish, perform, film or record a work and to authorise others to do so P24 Q1b(iii): copyright. It applies automatically to books, music, photos, software and websites.
  • Plagiarism = using someone else’s work or ideas as your own. Acknowledging the source by citing it avoids plagiarism P24 Q1b(ii): plagiarism.
  • Using copyrighted work legally: get permission/consent from the owner, use work with a suitable licence (e.g. Creative Commons), use it under fair use/educational use with credit, or use public-domain material. So a physics project may use a journal’s work with the author’s consent → TRUE P25 Q1c(iv).
  • To use an online song in a video follow the rules by making sure the use matches the licence (credit alone is not enough) → D P25 Q1a(i).

Creative Commons (CC) licences

  • Creative Commons licences let others use, share and adapt a work under conditions chosen by the creator P24 Q1a(x): B. The creator keeps the copyright; CC does not transfer ownership to the public domain, so “CC lets creators waive their copyright completely” is FALSE P24 Q1c(v) (check) (only CC0 waives rights).
  • BY = give credit (attribution). NC = non-commercial only. SA = share alike. ND = no derivatives.
  • CC BY-NC: others can remix/share the song but not for profit P25 Q1a(xiii): B.

Copyright vs Creative Commons

CopyrightCreative Commons
RuleAll rights reserved; you need permission for every useSome rights reserved; permission is given in advance with conditions
Effectprotects the creator’s income and control, but limits sharingencourages sharing, remixing and education while still crediting the creator

Citing sources (APA 7th edition)

  • In-text citation: placed inside the text, e.g. (Dorji, 2020) P25 Q1b(iii): in-text. Reference list: full details at the end.
  • Book format: Author, A. A. (Year). Title in sentence case, in italics. Publisher. Only the first word and proper names are capitalised; no city in the most recent (7th) edition.
Dorji, T. (2020). Public health challenges in Bhutan. Bhutan Health Trust Fund.
         (title in italics)        -> P25 Q1a(iv): C
Smith, J. (2021). The digital age: Psychological impacts of social media.
         HarperCollins Publishers. -> P24 Q1a(v): B (no place of publication)

Ethical online behaviour

  • Cyberbullying / fake accounts (Pema’s fake profile): can lead to school discipline (warning, suspension), legal action under the cyber/ICT laws, deleting the account, and harm to the victim P25 Q3a.
  • Good digital citizens: respect privacy, think before posting, give credit, report abuse, use strong passwords, and do not copy files without permission.

3 · Spreadsheets (MS Excel / Google Sheets)
P25 Q1a(ix,x,xv),b(v),c(ii),Q2a · P24 Q1a(i,iii,vi,xv),Q2a,Q4b

Key ideas

  • A formula starts with =. Cell reference = column letter + row number (B2). Range = A1:A6 (from A1 to A6). Formulas update automatically when the data changes.
  • Relative reference (B2) changes when copied; absolute reference ($B$2) stays fixed.

  • Tashi Dendup’s score: the names are in column B and the marks in C, so the table is B2:C5 and the marks are in column 2 of that table → =VLOOKUP("Tashi Dendup", B2:C5, 2, FALSE) = 78 → A P25 Q1a(x). Choosing a chart

  • Sales trend over five months → line chart (option D) because the line joins the points in time order and shows the rise and fall P25 Q1a(ix). A pie chart shows parts of a whole; a column chart compares categories; a scatter plot shows the relationship between two numbers.
  • To make a chart: select the data → Insert → Chart → choose the type → add title and axis labels P24 Q4b.

5 · Loops & Python Turtle
P25 Q1a(ii),b(iv),Q3e,Q6b,c · P24 Q1a(iv,vii,ix),c(iv),Q3c,Q4c,Q5a,b

for loop and range()

  • Use a for loop when you know how many times to repeat P24 Q1a(vii): D; use a while loop when you repeat as long as a condition is true P24 Q1c(iv): TRUE.
  • range(stop) = 0 to stop−1; range(start, stop); range(start, stop, step). The stop value is never included.
for i in range(1, 4):      # 1 2 3
    print(i)
for j in range(3, 0, -1):  # 3 2 1
    print(j)
for i in range(2, 10, 3):  # 2 5 8
    print(i, end=" ")      # end=" " keeps output on one line
  • Output of for i in range(1,4) followed by for j in range(3,0,-1) P25 Q3e: 1 2 3 3 2 1 (each on its own line, six lines). range(2,10,3) with end=" " prints 2 5 8 P25 Q6c.
  • Even numbers 1 to 15: for i in range(1,15): if i % 2 == 0: print(i) prints 2, 4, 6, 8, 10, 12, 14 → A P24 Q1a(iv) (option C misses 14; D prints 0).

Strings

  • A string is a sequence of characters; it is immutable: once created, its characters cannot be changed in place P25 Q4a. To “change” it you create a new string.
car = "Alto"
car[0] = "B"          # TypeError: strings are immutable
car = "B" + car[1:]   # new string "Balto" (the old one is replaced)
print(car)
  • P25 Q4b: modifying car shows immutability — direct item assignment fails, so a new string must be made (e.g. car = car + " 800" or "B" + car[1:]).

Lists: index, slice, methods

data = [10, 20, 30, 40, 50]
print(data[1:4])      # [20, 30, 40]  -> C
colors = ["red", "green", "blue"]
print(colors[-1])     # blue (last item)
my_list = ["Range", "function", "inbuilt", "variable"]
my_list.pop(2)        # removes index 2 ("inbuilt")
print(my_list)        # ['Range', 'function', 'variable']
  • Slice data[1:4] gives [20, 30, 40] (start included, stop not) → C P25 Q1a(viii). colors[-1] counts from the end, so the output is blue P25 Q4c. After pop(2) the list is [‘Range’, ‘function’, ‘variable’] → D P24 Q1a(xi).
  • Methods: append(x), insert(i,x), remove(x), pop(i), sort(), len(list).

Tuples

my_tuple = (10, 20, 30, 40)
print(my_tuple[1])    # 20 -> B
  • Index starts at 0, so my_tuple[1] is 20 P24 Q1a(xiii). Tuples use ( ) and cannot be changed; dictionaries use { } with key:value pairs and can be changed P25 Q4f.

Sets

Functions

  • A function is a reusable block of code that performs a specific task and can be called many times P25 Q1b(ii): function P24 Q1b(v): function.
  • Parameter = the variable in the definition (def hello(f_name)); argument = the value passed when calling (hello("Sonam")).
  • return sends a value back to the caller; print only displays.
  • Default argument: def add(a, b=10) — if the caller leaves out b, it is 10. add(5) → 15 is valid; add() fails (a is required); passing 3 arguments fails (only 2 parameters) → D P25 Q1a(vii).
  • Local variable: created inside a function and usable only there; global variable: created outside.
def add(a, b=10):
    return a + b

print(add(5))        # 15
print(add(5, 20))    # 25

Reading code (traces)

    return a*2 + 3

def addition(x, y):    # 1 = parameters (x, y)
    add = x + y
    return add
cal = addition(10, 5)  # 2 = function call, arguments 10 and 5
print(f'Addition:{cal}')   # Addition:15

Recursion

  • A recursive function calls itself on a smaller problem until it reaches a base case that stops the calls. It needs (1) a base case and (2) a recursive case that moves toward it.
def countConsonants(text):
    if text == "":                       # base case (paper shows " ")
        return 0
    elif text[0].isalpha() and text[0].lower() not in "aeiou":
        return 1 + countConsonants(text[1:])
    else:
        return countConsonants(text[1:])

print(countConsonants("Bhutan"))         # 4

Algorithm vs flowchart

  • An algorithm is a step-by-step set of instructions to solve a problem (written in words or pseudocode) P25 Q1a(xii): D. A flowchart is a diagram of the algorithm using standard symbols and arrows.

Formwritten steps in words / pseudocodediagram with symbols and arrows

  • Process is a rectangle, not a parallelogram; the parallelogram is for input/output. “In a flowchart, process is represented by a parallelogram” is FALSE P25 Q1c(v).

Flowchart to code

  • Convert each symbol: input → input(); process → assignment or calculation; decision → if (or while when the arrow goes back); print → print(); start/stop → begin/end.

balance = 1000                                   # (i) [1]

while True:                                      # (ii) [2] menu repeats

    print("3. Withdraw Money")

def mess_system():
